# Local Echo Example

An offline Provider API v1 example. It returns the last user text and never connects to a network. It does not execute tools or process images. Enter any display name to log in. This is a development fixture, not an AI service.

Edit `config.json` to change the prefix. Package with `python -m umeko_provider_sdk pack . echo-provider.zip`, then import through **Settings → Accounts & Providers → +**.
