# 五分钟上手 {#quick-start}

Umeko 把 Pi Coding Agent 放进原生桌面：围绕项目聊天，使用自己的模型服务，查看工具与子智能体的工作过程。

## 1. 安装应用 {#_1-install-the-app}

从[安装与更新](./install)选择平台和版本。完整安装包已携带运行时，不需要先安装 Python、Node.js 或全局 `pi`。

## 2. 添加模型 {#_2-connect-a-model}

进入 **设置 → 账号与供应商**。常见供应商可选择品牌、站点并填写对应 API Key；其他服务通过 API 供应商或可信的供应商 ZIP 接入。

填写完成后选择一个可用模型。订阅登录与 API Key 的权限和计费方式各有不同；使用哪种 Key，见[账号与模型供应商](../guide/providers)。

## 3. 打开项目 {#_3-open-a-project}

通过左栏添加项目，或把项目文件夹拖入左栏。打开一个聊天，确认工作目录和模型，再告诉 Umeko 想完成什么。

可以从这样一个小任务开始：

> 先阅读这个项目，告诉我怎么运行、主要目录的用途，以及你发现的三个值得改进的地方。先不要修改文件。

## 4. 看过程，补充要求 {#_4-follow-along-and-steer}

- 思考与工具记录可展开查看。思考区显示模型返回的思考内容，模型没有返回时就不显示。
- 运行中按 **Enter** 将补充内容排队，按 **Ctrl+S** 优先介入当前任务。
- 做出报告、图片或代码后，可以说「通过 submit 给我展示」，在聊天或右侧查看产物。
