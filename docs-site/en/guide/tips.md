# Things to try {#things-to-try}

You do not need to memorize every menu. Give me a goal, a scope and constraints so I can help more effectively.

## New to a project? {#new-to-a-project}

> Map this project's directories and explain how to run and validate it. Read only; do not edit files.

## A batch of tasks? {#a-batch-of-tasks}

> Have separate subagents review these three documents, then combine recurring issues into one list. Do not edit the originals yet.

Delegate independent work; let the main agent combine findings and validate. [Learn delegation](./subagents).

## Did you know I can change the app's look? {#did-you-know-i-can-change-the-app-s-look}

> Create and apply a pure-white theme with readable text. Keep my current character.

Themes and characters are separate. Export the character-making Skill to create your own look. [Appearance guide](./appearance).

## Give me a new skill {#give-me-a-new-skill}

> Find a Pi extension for this task. Explain its source and purpose first, and install it into this embedded Pi only after I agree.

Skills guide tasks, extensions add behavior, and MCP connects services. Choose the right kind first. [Extension guide](./skills).

## Made something? Show me {#made-something-show-me}

> Save the report as Markdown and show it with submit. Put the charts directly in chat too.

No need to hunt through file paths yourself. [Artifact previews](./artifacts).

## Going the wrong way? Steer me {#going-the-wrong-way-steer-me}

> Pause visual polish and prioritize the sign-in failure. Do not change the database schema.

Use Ctrl+S during a task to prioritize an intervention; Enter queues a follow-up. Say both what to do and what to leave alone.

## A plugin broke? Let me inspect it {#a-plugin-broke-let-me-inspect-it}

> Inspect the current Pi, extension and network settings. Explain likely causes first; do not reinstall or erase configuration.

Versions, error details and repeatable steps help more than “it's broken.” [Reporting checklist](../troubleshooting#report-a-problem).

## Spend tokens where they matter {#spend-tokens-where-they-matter}

> Start with a short plan and make only the necessary changes. Explain before expanding the scope.

Focused context is easier for the model to follow. Record decisions in project documents and compact after milestones. Concurrent agents and retries can incur additional model charges.
