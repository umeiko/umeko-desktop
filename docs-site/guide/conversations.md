# 项目、聊天与任务状态 {#projects-conversations}

## 围绕项目组织 {#organize-by-project}

左栏中的项目对应实际工作目录，一个项目可以有多个独立会话。拖入目录可添加或重新打开项目。右键项目或会话管理名称、固定、归档等；从左栏移除项目只移出列表，项目文件保留在原处。

拖动左栏边缘可调宽度，**Ctrl+B** 展开或收起。切换聊天时先展示加载提示，再加载原生历史；草稿、附件和阅读位置分别保存。

## 看懂正在发生什么 {#understand-task-states}

运行指示表示任务仍在工作，绿色未读标记表示后台会话完成后还未查看。思考、工具调用与最终回复分开显示，点击折叠标题查看详情。模型返回思考内容时才会显示思考区。

[![展开思考过程与工具记录](/images/process-zh.png)](/images/process-zh.png)

*展开「思考过程」和「执行了 … 项操作」，分别阅读推理与工具结果。*

每条工具记录显示那一次操作的结果，任务是否完成看最终回复。工具失败时，查看对应结果或请求详情，再决定重试或调整要求。

## 排队与 steering {#queue-and-steer}

| 操作 | 效果 |
| --- | --- |
| 空闲时 Enter | 发送消息 |
| 运行时 Enter | 作为后续消息排队 |
| Ctrl+S | 优先介入；输入为空时提升队首消息 |
| 停止 | 中断当前任务；已经写入的文件保持现状 |

队列可编辑、删除或引导。附件可拖入聊天区；复制的文件、图片与文本也可以粘贴。浏览旧消息会暂停自动跟随，滚回底部可继续跟随。

## 上下文与压缩 {#context-and-compaction}

模型旁的圆环展示上下文用量。点击可在空闲时手动压缩，自动压缩遵循 Pi 配置。压缩用摘要替换较早的内容，让会话在模型的上下文窗口内继续。重要约束请写进项目文件。

## 关闭窗口和通知 {#closing-and-notifications}

关闭主窗口会收到系统托盘，后台任务继续。真正退出请右键托盘头像选择 **退出**；没有托盘的桌面会最小化到任务栏。

最小化或隐藏期间完成任务会发送系统通知，前台超过三分钟的任务也会通知。点击通知回到相应会话；通知声音、勿扰与侧边历史由 Windows、macOS 或 Linux 桌面控制。
