Umeko adapts capture and replay to use per-session in-memory environment maps and
adds Windows PowerShell capture, fresh Windows environment values and executable
ordering. The Apache 2.0 license text is provided in tzdata-APACHE.txt.
The unified execution adaptation uses Umeko's job registry and pipes with its
Windows job host, bounded reads, and separate full-output files.
