# 温水和彦子智能体形象 · 旧版生成记录

当前形象使用 [v2](../kazuhiko-v2/README.md)。旧稿已从当前检出移除，generation.json 中的历史图片链接固定到清理前的 Git 提交，文件清单与校验值见 [archived-assets.json](../../archived-assets.json)。

提供头像、回复图与接文件动作，用于普通子智能体和全局子智能体，不加入主角色或桌宠候选。官方参考来自 https://makeine-anime.com/character/ 的温水和彦立绘与头像；原始文件保存在 reference。

由内置 image_gen 生成，完整提示词见 generation.json 与各 prompt.txt。运行 python3 build.py 兼容旧入口并转到 ../kazuhiko-v2/build.py，只构建当前版本，避免旧稿覆盖发行素材。
