# 稀有角色场景

本目录为最初概念稿，已由 ../v5 的透明半身插画与用户指定对白替代。此处保留修订记录；build.py 会转到 v5 打包。

由内置 image_gen 生成透明场景图，完整提示词、参考图路径、官方出处和原始输出位置记录在 generation.json。对白是适合界面的简短改写，不标作原作逐字台词。鲸鱼娘是原创场景。

覆盖四位内置主角色（八奈见、小鞠、佳树、天爱星）及现有四位桌宠（八奈见、小鞠、天爱星、鲸鱼娘）。温水和彦目前只提供子智能体形象。

新任务封面按会话和当前角色抽取一次，概率 0.005，最多缓存 128 条结果；普通界面通知不会重抽。桌宠在完整待机动画结束时抽取一次，静态场景展示一轮约 4.2 秒后再次抽取。隐藏、暂停、繁忙或互动中不会抽取，不增加模型调用或常驻图片缓存。

重新打包时先运行角色/桌宠各自的 build.py，再运行本目录 build.py。它只缩放和编码已有透明图片，不重新绘制。
