# 半身彩蛋插画

当前主页彩蛋插画版本。五位角色均为透明背景、带完整双手的半身构图；不合成场景背景。八奈见、小鞠、佳树的神情依照用户最后提供的参考图，天爱星保留害羞微笑，鲸鱼娘保留大头比例和讨米的神情。桌宠不使用这些半身图，而使用 art/desktop-pets/rare-idle-v1 的独立全身动画。

天爱星进一步收窄脸颊、拉长脸型，缩小眼睛，使五官接近原作插画及动画；该次修订记录在 ../v6。天爱星与佳树随后分别修正交叠双手和胸前手的手指，选用 tiara-hands-fixed.png、kaju-hands-fixed.png，手部修订提示词与原始生成记录在 ../v7。

对白使用用户指定的中文措辞，绘制时不把文字写入图片。小鞠的原文语境可对应小说第六卷 203–204 页的阅读笔记，天爱星由用户指定第八卷插画；八奈见和佳树暂未核实具体卷页，不附加未经确认的出处。鲸鱼娘为用户指定的原创台词。

完整提示词、输入参考、内置 image_gen 原始输出位置见 generation.json；每张提示词也单独保存在同名 .prompt.txt。旧版本保留作修订记录。

运行 `python3 art/rare-scenes/v5/build.py` 只更新主页插画与目录；桌宠彩蛋须运行 `python3 art/desktop-pets/rare-idle-v1/build.py` 单独打包。两者只缩放和编码，不修改画面或透明度，沿用 0.005 概率及既有抽取/缓存策略。
