# 小鞠桌宠原画与动画

使用内置 image_gen 制作。`generation.json` 保留每个状态的完整提示词、参考来源和生成文件名；`source/` 是六组原始透明 3×2 动画图。角色身份参考现有小鞠人设包，比例与线条参考八奈见桌宠。

待机抱书、思考读书、工作写字、等待确认、完成竖拇指、出错时害羞地摸脸。眨眼顺序为张眼、轻微呼吸、半闭、闭眼、半开、恢复。画面使用统一画布、人物高度和脚底基线。

安装 Pillow 后运行 `python art/desktop-pets/komari-v1/build.py`，会重新切分、注册并编码六段透明循环 WebP 到 `umeko-plugins/desktop-pet/assets/komari/`。无需调用图片 API。这里只进行图集打包，不绘制或替换原画。

打开 `preview.html` 可同时检查六种状态与明暗背景。原始图与本目录工具不随桌面安装包分发，正式资源只包含清单、WebP 与生成记录。
