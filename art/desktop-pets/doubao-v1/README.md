# 豆包桌宠

使用主角色的经典短发、黑色针织上衣与红色围巾，以现有鲸鱼娘桌宠的二维 Q 版线稿和赛璐璐色块为画风参考。独立的二维全身母版固定人物比例、服装和画风，不复用主界面的 3D 半身图。六种任务状态和稀有待机分别绘制独立的十二帧连续关键姿势。

`generation.json` 保留每张动作图的提示词、参考和原始生成记录。运行 `python build.py` 按 4×3 网格切帧，使用同一动作内固定缩放比例，并对齐脚底与水平位置，输出与鲸鱼娘一致的 360×360 透明循环 WebP。该脚本只裁切、对齐、等比缩放与编码，不重绘角色，也不生成中间动作。

桌宠通过自己的形象选择独立切换；主角色、普通子智能体和全局子智能体的接入见 `art/characters/doubao-v1`。

画风参考图随附原鲸鱼娘项目的 MIT 许可，见 `reference/whale-girl-MIT.txt`。参考图只用于对齐画风；豆包动作图由内置 image_gen 独立生成。
