# 委派子代理：使用不同模型 / subagent delegation / multi-model

需要委派子代理、并行任务或让另一个模型处理任务时，直接使用现有的 `subagent` 工具。**不要搜索 Pi 的 models.json 或供应商配置方式，也不要使用系统 pi CLI。** Umeko 已在运行中的内核统一包装供应商，`model` 必须使用下表的完整调用名称；界面的供应商名称不是调用名称。

## 调用步骤

1. 从上表复制 `umeko/别名`，填入 `subagent` 的 `model`。不指定模型时省略该参数，继承当前模型。
2. `prompt` 描述具体任务、交付物和限制。工具参数以当前已注册工具的 schema 为准；需要时先发现 `subagent`，不要凭空构造 shell 命令。
3. 为不同任务选取不同模型时，分别调用 `subagent`；观察返回的任务状态。启动成功不等于任务已完成。子代理完成后会按运行机制通知主代理，必要时使用结果/等待工具继续跟进。

如果手动指定的模型不存在，错误结果也会返回全部可用的正确调用名称。阅读并选择列表中的值重试一次，避免轮流猜测供应商命名。模型、凭据及网络配置统一由 Umeko 管理，参见 [供应商文档](providers.md)。
