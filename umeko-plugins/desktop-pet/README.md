# 桌面小宠物

官方内置 Widget，默认显示桌宠并保持置顶。显示与置顶可在本页调整。

每 1–2 秒读取已加载聊天的忙碌、思考、工具执行、等待确认、网络重试和完成状态，任何动作至少保持 3 秒。动画观察不调用模型、不扫描历史。切换聊天或隐藏主窗口后仍继续观察；退出 Umeko 时停止。

- 左键点击：角色回应并触发互动动作。
- 左键双击：已绑定全局子智能体时，弹出单行任务输入框；回车或点击发送直接发给绑定的悬浮小助手，忙碌时沿用其消息队列。Esc 或点击框外收起，发送失败保留输入；未绑定时不弹出。
- 按住拖动：移动桌宠，松手后保存位置。移到其他屏幕也会约束在可见区域。
- 右键：打开 Umeko、进入桌宠设置、选择形象、暂停动作、置顶、调整大小、重置位置或隐藏。
- 隐藏后释放动画解码器，后台观察继续运行。停用 Widget 则停止观察并隐藏。

## 本机提醒与待办

右键“提醒与待办”可查看前三条未完成事项、新增或打开独立管理窗口。窗口采用与 Umeko 主窗口相同的无边框、边线、拖动和缩放方式；不切换主页面。形象与桌宠偏好留在 Widget 设置，事项及到期气泡开关全部在小窗口内管理。

标题必填、备注可选；不设置时间是普通待办。设置时间后可选择“单次”或“每日”，日期、时间使用滚轮选择器。每日提醒保存 IANA 时区及当地钟点，夏令时切换后仍保持同一当地时间；不存在的钟点顺延至当天第一个有效时刻，重复钟点一天只触发一次。长期休眠或退出后只处理最近一次待处理事件，不逐日补播。完成每日事项会停止后续循环，删除可移除整个事项。

到期事项会在桌宠头顶显示红点和持续气泡，直到用户点击“查看”才清除未读状态；不会自动完成事项，子智能体收到消息也不会清除红点。未读状态保存在本机，重启或重新显示桌宠后仍保留；关闭到期气泡时暂不显示，重新开启后显示尚未查看的事项。暂停动画不影响计时。没有系统通知或声音。

到期数据也会通知事项关联的“悬浮小助手”，在它自己的全局对话中出现。投递队列与用户未读状态分别保存，暂时停用全局子智能体时等待恢复；不将已删除目标的通知转交其他智能体。消息只作为提醒数据，不授权执行备注中的指令。

在下面导入 WebP / GIF / PNG，或包含多种动作的 ZIP。单段动画会作为所有状态的回退。多状态形象包格式和 Agent 管理方法见包内 `AGENT.md`。自定义形象和偏好保存在用户数据目录 `desktop-plugins/state/desktop-pet/` 与 `desktop-plugins/settings.json`，升级不会覆盖。

内置八奈见杏菜、小鞠知花、马剃天爱星和鲸鱼娘，可在动画形象下拉框或桌宠右键菜单切换，内置形象不可删除。选择独立于聊天主角色，升级和重启保留偏好。

八奈见的六种状态及稀有待机均使用用户提供的透明循环 GIF，统一为 320×320 画布和鞋底基线。减少帧数后保留各动作的原始循环时长。来源与处理记录见 `assets/yanami/delivery.provenance.json` 和 `assets/yanami/idle.provenance.json`。

鲸鱼娘的六种透明动画复用社区 [dsh-whale-girl-pet](https://github.com/yanzwzz/dsh-whale-girl-pet)，保留 MIT 许可与贡献者署名。原始动画转为 360×360、10 fps 的循环 WebP，无需网络或额外视频组件；只有当前动作参与播放，隐藏后释放解码器。来源版本、校验与动作映射见 `assets/whale-girl/source.json`，许可见 `assets/whale-girl/LICENSE.txt`。开发者可用 `scripts/prepare-whale-pet.py --ffmpeg <ffmpeg路径>` 重新制作资源，应用和常规构建不会自动下载。

待机动画每完整播放一轮，有 0.5% 概率出现与普通待机画风和比例一致的全身彩蛋动画与用户指定台词；隐藏、暂停、忙碌和互动时不会抽取。稀有图只在显示时加载，不消耗模型 Token。桌宠动画提示词与生成记录见 art/desktop-pets/rare-idle-v1；主页半身插画独立打包。

豆包内置形象使用独立二维全身动画，包含六种任务状态及稀有待机彩蛋；完整生成记录与参考许可见 `art/desktop-pets/doubao-v1`，运行资源见 `assets/doubao`。

## 悬浮小助手与人物设定

显示桌宠且启用“全局子智能体”后，应用自动创建并绑定唯一的“悬浮小助手”。隐藏桌宠或停用任一服务即停止这条主动通知路径，重新显示不补播隐藏期间的任务。再次启用复用原有助手及其历史；不会按同名绑定用户自己创建的智能体，也不会自动连接项目。

真实任务执行严格超过 90 秒，结束后才发送结果简报给助手。简报只包含来源、运行标识、耗时、真实终态和有限的最终结果；多项完成会合并，最多保留最近 8 项待处理简报，更多完成合并为计数，不读取完整历史。助手使用现有全局模型与 Pi，可能产生模型调用；没有可用模型时不启动。助手自己的完成不触发通知循环。

“人物设定”按形象保存，默认来自包内可选的 `persona` 字段；可以留空，也可恢复包默认。内置五种形象均带简短设定，旧 ZIP 没有此字段仍可使用，无需升级包格式。设定只影响性格与说话方式，不改变权限。

专属 `send_to_user(text)` 仅对当前绑定的助手开放。每段最多 80 个可见字符，优先 10–30 字；支持连续分段，不设固定每秒配额。工具按中英文、长度和标点计算约 1.8–14 秒的阅读时间，异步等待后返回，并行调用也依次显示；气泡按同样时长停留，界面仍可操作。不会挤掉提醒卡片；隐藏、绑定失效或取消会停止后续发送。


悬浮小助手可读取 `widgets.docs`（`id: scheduled-tasks`），并通过 `widgets.call` 使用已启用的定时任务 Widget，为自己创建与管理全局计时器；通过 `widgets.result` 查看调用结果。默认目标就是它自己，仅能查看和修改目标为自己的全局计时器，不能改投其他智能体或前台会话。计时器保存稳定的助手身份，重启后仍可唤醒原助手；隐藏桌宠、停用绑定服务或删除助手时不会向别处投递。普通会话的计时器、共享配额及 Agent Bus 权限保持原有行为。


## reminder() 工具

关联桌宠的全局子智能体拥有专属 `reminder()` 工具，与提醒窗口共用现有数据。`action` 为 `list`、`get`、`create`、`update`、`complete`、`delete`；创建或修改支持 `title`、`notes`、带偏移的 ISO 8601 `dueAt`、`repeat: once|daily`、每日提醒的 IANA `timeZone`。只有该子智能体关联的事项可以访问，工具不能清除用户未读标记。列表支持 `status`、`offset`、`limit`，默认每页 50，最多 100。

到期气泡的“查看”打开提醒首页，未完成的到期事项以红色显示；点列表正文才编辑。已完成页支持逐项删除和清空，清空仅删除已完成事项，确认后一次保存。

已完成事项仍可编辑标题、备注和时间；仅修改文字会保留完成状态，重新设定提醒计划则恢复待提醒。勾选完成会立即保存，但该行在当前列表保留完成样式；切换页面或关闭重开后再移入已完成页。

复选框可取消完成：当前列表保留的完成行原位恢复，已完成页取消勾选后立即移回未完成页。`completeItem {"id":"...","completed":false}`（或 reminder action=complete、completed=false）恢复原计划；逾期恢复只显示红色，不重播已错过的通知，每日事项继续下一次计划。

宠物输入框的消息带 `(input from pet)` 来源标记。宠物助手处理这类消息和各类宿主通知时优先通过气泡回复；直接在全局智能体聊天框提问时可以普通聊天展开回答。
