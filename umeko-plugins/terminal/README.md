# 终端

使用真正的伪终端：Windows 为系统 ConPTY，macOS/Linux 为 POSIX PTY。界面采用紧凑工具栏、顶部终端列表和下方全宽终端区，使用官方 Codicons。列表与终端区之间的横线可拖动调整高度。

- 加号创建终端，旁边下拉选择 Shell；拆分按钮创建同组终端，最多上下两栏，分隔线可拖动调整比例。
- 分栏终端在列表中相邻排列，通过左侧连线和缩进标明同组关系；点击工具栏、终端行或右键菜单的“取消分栏”可恢复独立显示，进程、输出和聊天关联保留。
- 右键终端可拆分、重命名、清屏、关闭，或附加到当前聊天。F2 重命名，Ctrl+Shift+5 拆分。
- 用户和 Agent 共用同一个终端进程、工作目录、环境变量及交互程序，Agent 的命令会在可见终端中输入。
- “附加到当前聊天中”将当前语言的终端引用写入聊天输入框，不自动发送。只有用户关联过的聊天能通过 Agent 接口读取和操作该终端。
- Ctrl+C 中断；有选中文字时复制。Ctrl+Shift+C/V 复制、粘贴，Shift+PageUp/PageDown 查看历史。支持中文输入法和 ANSI 颜色。
- 默认 12px 等宽字体，优先使用 Cascadia Mono / Consolas，浅色界面为白底深色字及蓝色光标；支持 ANSI 16 色、256 色及 RGB 真彩色，并保留深色主题的适配。
- 关闭面板、切换聊天不会关闭终端；垃圾桶关闭所选终端及其进程，停用/卸载插件或退出应用会清理全部终端。

终端不跨应用重启恢复。配置变更会重启插件并关闭全部终端；输出历史有界保存于内存。默认保留 1000 行，可在插件配置中调整。渲染只绘制当前可见行，输出合并后更新，关闭面板时停止界面帧传输。

Agent 接口与实际参数见 [AGENT.md](AGENT.md)。终端原样执行用户或 Agent 输入的命令，具有当前系统用户权限。

VT 状态解析使用 pyte 0.8.2（LGPL-3.0）、wcwidth 0.2.13（MIT），POSIX PTY 使用 ptyprocess 0.7.0（ISC）。可修改源码、许可证与来源校验值完整包含在 `vendor/`。重新准备依赖运行项目根目录的 `scripts/prepare-terminal-vendor.py`。
