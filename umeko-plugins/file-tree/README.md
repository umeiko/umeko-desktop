# 文件管理器

列表使用 VS Code Explorer 的 22px 行高、8px 缩进和 16px 图标，按 Umeko 字号比例缩放；文件图标使用 VS Code 的 Seti 字体与文件/语言关联，工具栏使用官方 Codicons。来源及许可证保留在 `assets/` 中。筛选默认收起，可点击漏斗或使用 Ctrl+F 打开。

Umeko 官方演示插件。读取当前会话的工作目录，采用 VS Code Explorer 的文件夹展开、紧凑行、类型图标和缩进线交互。

- 文件夹逐层加载，不递归扫描整个项目。
- 搜索当前已加载的条目，隐藏文件可切换。
- 文件单击只选中，双击才附加到聊天；文件夹单击展开或收起。右键提供预览、打开方式、系统定位、剪切、复制、绝对/相对路径、重命名与永久删除。文件键盘快捷键只在列表拥有焦点时生效，永久删除先确认。
- 重命名在文件所在行直接编辑，默认只选中文件名，保留扩展名；Enter 确认，Esc 取消，失败时保留输入供修改。
- 不跟随目录符号链接，不访问当前工作目录之外的路径。
- 默认每层最多显示 1000 个条目；超出会显示提示，可在配置中调整。

插件页面、Python 实现和配置均在本包内，可作为自定义插件的起点。
