# Pi 插件管理 Widget

用户从 Widgets 打开此页，管理当前会话的 Pi 插件及逐工具开关，关闭后页面工作进程停止。本 Widget 无 Agent 方法，也不提供在线市场。

提供标准 Pi（8 个原生工具）、极简（read/bash/edit/write）、默认（全部已配置能力）、自定义四个预设。配置保存在当前会话的 piCapabilities 元数据；调整开关自动转为自定义，预设切换保留上次自定义。禁用插件不加载其扩展模块，禁用工具从实际 Pi 注册表排除，包括间接调用。

内置页面的会话开关立即生效，不改写个人/项目设置。安装、卸载和全局变更仍需宿主确认。运行任务时不能修改能力；Agent 安装扩展继续使用 run_pi_command。
