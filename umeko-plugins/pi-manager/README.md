# 插件管理

从 Widgets 打开，关闭侧栏即停止页面工作进程，也可在 Widgets 中停用。

- 搜索本地已安装的 Pi 扩展。
- 查看本地说明、工具、主页与源码链接，按需检查更新。
- 选择全局启用、本对话启用或本对话暂时禁用。
- 粘贴 `pi install npm:包名`、Git 来源或本地路径安装；更改前由宿主确认。

[浏览 Pi 官方插件目录](https://pi.dev/packages)。本 Widget 不抓取在线推荐，也不自动安装或更新。

页面仅使用 Widget SDK 的 `pi.read` 和 `pi.manage`，不访问宿主后端、密钥或供应商设置。清单分页，说明文本有大小限制，关闭页面后不继续轮询。

安装失败时自动尝试系统代理/直连与自定义 CA/系统证书组合，随后尝试下载包和离线安装。临时网络故障会退避重试，可以取消安装；关闭此 Widget 也会取消它发起的安装。证书验证始终启用。Umeko 的基础扩展固定启用，MCP 与社区扩展可分别设置。


工具可见性按会话保存。包列表中的绿色标签表示可用，红色表示不可见；点开包，在工具名后的复选框中修改。Pi 原生工具与 Umeko 内置工具也支持此设置。任务及其子代理结束后可修改；会话下次运行时使用新的工具清单。隐藏的工具不会出现在 Agent 的工具清单、工具搜索或组合调用中，子代理继承同一限制。它不撤销历史消息中的文字，也不是对 shell 或插件代码的沙箱。
