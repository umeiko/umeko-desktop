# Pi 插件管理

从 Widgets 打开，配置只影响当前聊天，不改写个人或项目的 Pi 设置。关闭侧栏停止页面工作进程。

- **标准 Pi**：启用 8 个原生工具：`read`、`bash`、`powershell`、`edit`、`write`、`grep`、`find`、`ls`，关闭 Umeko Desktop 与其他扩展能力。
- **极简**：仅启用 `read`、`bash`、`edit`、`write`。
- **默认**：使用当前配置的全部 Pi、Umeko 与扩展能力。
- **自定义**：展开插件，逐个开关工具；调整任意开关会转为自定义。切换预设会保留上次的自定义配置。

插件开关控制整个插件；关闭后，其工具及扩展钩子不加载。工具开关只控制该工具，保留插件的其他功能。工具搜索和代码执行也不能调用已关闭的工具。未加载过的插件先启用一次，即可读取它注册的工具。

可按插件名、工具名或说明搜索。工具说明放在鼠标悬停提示中。会话正在执行任务时，结束后再调整；历史聊天恢复自己的配置，新聊天使用默认模式。

安装失败时自动尝试系统代理/直连与自定义 CA/系统证书组合，随后尝试下载包和离线安装。临时网络故障会退避重试，可以取消安装；关闭此 Widget 也会取消它发起的安装。证书验证始终启用。所有列出的扩展（包括 Umeko 内置扩展、MCP 与社区扩展）及其工具都可按当前会话开关。内置管理页的会话开关直接生效，安装及其他全局变更仍需宿主确认。

[浏览 Pi 官方插件目录](https://pi.dev/packages)。本 Widget 不抓取在线推荐，不自动安装或更新。页面仅使用 Widget SDK 的 `pi.read` 和 `pi.manage`，不访问宿主后端、密钥或供应商设置。

安装失败时尝试系统代理/直连与自定义 CA/系统证书组合，随后尝试下载包和离线安装。临时网络故障会退避重试，可以取消安装；关闭此 Widget 也会取消它发起的安装。证书验证始终启用。

已有的逐工具可见性配置会作为自定义配置继续保留。首次打开会异步读取真实工具清单；加载失败会停止轮询，点击刷新可重试。
