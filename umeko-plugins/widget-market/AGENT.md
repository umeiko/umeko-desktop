# Widget 市场 / Widget Market

此页只浏览固定 GitHub Releases 发布源，通过异步 Widget SDK 请求宿主执行列表、下载检查、安装和卸载。没有 Agent 方法，不允许自定义源、外部打开、后台轮询或启动时联网。权限和安装确认由宿主负责。安装后需在“设置 > Agent > 插件管理”启用；本地 ZIP 也在那里导入。

This page browses the fixed GitHub Releases source through asynchronous Widget SDK host requests. It exposes no Agent methods, source configuration, external links, background polling or startup networking. Umeko owns permissions and installation confirmation. Enable installed Widgets or manually import a local ZIP in Settings > Agent > Plugin Management.
