# 全局子智能体

通过聊天右下角的 Widget 入口打开「全局子智能体」。创建时选择已配置模型、角色形象和职责，默认形象与当前外观设置一致。名称可留空，使用所选人物名；多个同人物的自动命名实例使用 `人物名-1`、`人物名-2` 等编号，自定义名称不变。点击头像可以修改代理；删除代理会停止运行并移出列表，原始上下文文件保留在配置目录中以供恢复。

每个代理拥有自己的持久 Pi 上下文。用户可以直接聊天；运行中发送的内容作为 steering 排队。最多保留 16 个代理、同时运行 4 个，关闭页面继续工作，停用 Widget 会停止其代理。重启不会自动恢复模型任务或重发桥接请求。

在「智能体总线」中由用户逐个启用普通会话。全局子智能体可看到工作区、会话与子代理的状态元数据，只能向启用的会话发出任务。会话内子代理由所属会话协调，不单独接受跨会话指令。每条任务有请求 ID、投递状态及明确结果；已投递不代表成功。关闭智能体总线取消相关未完成请求，已经执行的操作无法撤销。

全局子智能体是协调者，直接工具限定为宿主桥 API；工作区的文件、终端等操作由目标会话在其原有权限下执行。代理消息不继承用户的授权，重要操作仍遵守目标会话的确认要求。

界面仅加载最后 64 条、总计约 9.6 万字符的消息摘要；完整上下文保存在原生 Pi 会话文件。智能体总线队列与历史有上限，超时及中断明确显示，不会以重复发送掩盖失败。

模型可以请求创建：默认弹出预填表单，用户点击“创建”后才生效。“允许自动被创建”默认为关闭；开启后来自模型的请求直接创建。未指定形象时，从设置中的现有候选人物随机分配。创建成功后自动连接来源会话与新实例，不自动启动模型任务。

智能体总线按“项目 → 会话”定位，点击会话进入二级列表，每个复选框仅控制该会话与对应全局子智能体的一条双向链路。全局子智能体也可通过宿主 API 查看和管理自己的连接。未连接的实例不出现在普通会话的全局列表中；列表显示 idle 或 busy 持续时间。来自总线的消息逐条处理，聊天上方显示待处理队列，可删除或优先处理，优先不打断当前任务。
