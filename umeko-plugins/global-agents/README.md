# 全局子智能体

通过聊天右下角的 Widget 入口打开「全局子智能体」。创建时选择已配置模型、角色形象和职责，默认形象与当前外观设置一致。点击头像可以修改代理；删除代理会停止运行并移出列表，原始上下文文件保留在配置目录中以供恢复。

每个代理拥有自己的持久 Pi 上下文。用户可以直接聊天；运行中发送的内容作为 steering 排队。最多保留 16 个代理、同时运行 4 个，关闭页面继续工作，停用 Widget 会停止其代理。重启不会自动恢复模型任务或重发桥接请求。

在「智能体总线」中由用户逐个启用普通会话。全局子智能体可看到工作区、会话与子代理的状态元数据，只能向启用的会话发出任务。会话内子代理由所属会话协调，不单独接受跨会话指令。每条任务有请求 ID、投递状态及明确结果；已投递不代表成功。关闭智能体总线取消相关未完成请求，已经执行的操作无法撤销。

全局子智能体是协调者，直接工具限定为宿主桥 API；工作区的文件、终端等操作由目标会话在其原有权限下执行。代理消息不继承用户的授权，重要操作仍遵守目标会话的确认要求。

界面仅加载最后 64 条、总计约 9.6 万字符的消息摘要；完整上下文保存在原生 Pi 会话文件。智能体总线队列与历史有上限，超时及中断明确显示，不会以重复发送掩盖失败。
