# Skill 管理

从 Widgets 打开，默认显示当前聊天可用的 Skill。可切换全部、搜索名称或简介、按来源与全局默认筛选、按名称排序或按来源分组。列表使用单行布局；右侧勾选框请求改变当前聊天的可用状态。上下键选择，空格请求切换，回车打开底部详情。面板获得焦点时 Ctrl+F 定位搜索。

底部详情显示简介、渲染后的 SKILL.md、随附文件、字节大小和来源路径，并单独提供全局默认、打开目录和可卸载来源包的操作。正文按需读取；移出不清除已读内容，文件大小也不代表 token 用量。

“导入”接受本地 Skill 文件夹、ZIP 或 `.skill` 归档；也可将单个本地文件或文件夹拖入面板。先选择当前项目或全局范围并预览名称、简介和校验结果，同名条目可跳过或替换；来自不可替换来源及格式无效的条目只能跳过。提交后由宿主在面板内确认，确认前不写入。导入结果和逐项错误保留在页内，返回目录时刷新清单。导入不执行 Skill 脚本。

安装页接受 npm、Git 或本地包来源，可选当前项目或全局范围，显示进度、取消和错误。Pi 安装与卸载都处理整包，可能同时影响包内的扩展、模板和其他 Skill。所有变更由宿主在面板内确认；Widget 只发送请求，没有批准接口。不支持所需宿主接口时会提示升级。

图标使用 [Feather Icons v4.29.2 的 layers.svg](https://github.com/feathericons/feather/blob/v4.29.2/icons/layers.svg)，作者 Cole Bemis，按 MIT 许可分发。为适应面板配色，仅调整描边颜色；Widgets 入口和面板行共用同一文件。完整许可保留于 [assets/Feather-MIT.txt](assets/Feather-MIT.txt)。
