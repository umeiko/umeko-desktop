# Skill 管理

默认启用。Widget 的全局开关和当前会话开关联动控制 Pi 的技能发现、简介索引及原生技能调用；停用不删除文件或修改原有 Pi 资源过滤配置。重新启用后恢复原配置。关闭右侧面板只收起界面，正在执行的任务在本轮结束后应用新开关。

从 Widgets 打开，上方是「工作区」「全局」两个可折叠分区，下方是所选 Skill 的 Markdown 说明。拖动中间分隔条可调整两栏高度。列表显示名称和灰色介绍，支持搜索。预装技能按软件语言显示中英文介绍；第三方技能及用户修改过的文件保留原有介绍。每个条目代表一个完整 Skill 文件夹，不展开包内文件；每项行尾有复选框，单独控制当前会话是否启用该 Skill，选择自动保存，不修改 Pi 全局或工作区默认设置。任务或子代理运行时，结束后再调整。不提供新建功能。

单击条目更新下方只读预览，不改变配置；复选框直接保存启停状态，不弹二次确认。最近八项预览会缓存，刷新目录会重新读取。双击把整个 Skill 文件夹附加到当前聊天的输入框，不发送消息。右键可附加到聊天、打开独立预览、通过系统关联应用编辑 SKILL.md、在文件管理器中查看、复制整个文件夹、复制目录路径、粘贴、重命名或删除。独立预览的返回按钮会回到原 Widget 并保留其状态。重命名只改文件夹名，SKILL.md 元数据由文件编辑器或 Agent 管理。

复制使用系统文件剪贴板；粘贴直接导入选中的分区，拖入则按落点所在分区导入。支持本地 Skill 文件夹、ZIP 或 `.skill` 归档，无需切换到导入页或再次确认。成功后原地刷新列表，保留搜索、折叠及滚动位置；只有失败才在当前面板弹窗提示。校验失败或发现重名时整批拒绝，不覆盖原文件，也不执行 Skill 脚本。

“导入”按钮仍提供显式选择当前项目或全局范围、预览名称与校验结果的入口；需要替换重名项时可在此选择跳过或替换，再经宿主面板确认。重命名、删除和替换导入的确认均在本 Widget 内，不能由插件批准。目录操作不跨出批准的全局或工作区技能目录；删除不跟随技能资源中的链接。大目录有扫描、分页和字节预算，不会一次渲染全部条目。

工作区 Skill 放在 `<workspace>/.pi/skills/<name>/SKILL.md`，全局 Skill 放在当前配置的 `<agentDir>/skills/<name>/SKILL.md`；agentDir 未配置时是 `~/.pi/agent`。创建与维护由 Agent 使用已有文件工具完成，格式与位置见本插件 Agent 文档和按需查询的「Pi 扩展、Skills、MCP」文档，无新增 Agent 管理工具。额外路径或 npm 包的扩展管理仍由 Pi 自身处理，不列入这两个目录分区。

键盘：方向键定位、Enter 附加、F2 重命名、Delete 删除、Ctrl+C 复制、Ctrl+V 粘贴、Ctrl+F 搜索。预览复用 Umeko 右侧文档预览器。图标为本项目的 SVG 拉链归档盒，入口和列表共用。
