# 本轮变更审查

内置、默认关闭。在插件管理中启用后，任务正常完成、用户中止或主 Agent 进程退出时自动展开右侧面板。关闭面板不会停止采集；停用插件立即停止并清理快照。后台聊天不会抢占当前聊天的面板。整个应用只保留最近一次完成结果，并保持它的聊天归属。

基线是**本轮开始前的工作目录 → 本轮结束后的工作目录**，不是 HEAD 或暂存区；包括原有脏文件的本轮增量、新增和删除。相同目录中用户、后台进程或其他会话的并发编辑也会包含在内，不代表每项都由 Agent 修改。刷新保留开始基线，重新采集当前目录；任何聊天再次开始任务都会清除上一轮结果。仅捕获主 Agent 的完整 loop，包含同一 loop 中工具和子代理在该目录中的修改；不会在每个 token 或工具结束时扫描。

使用系统 Git 的对象、独立索引和 diff-tree。项目的 .git/index、分支、历史和文件均不被修改；非 Git 目录也可审查。遵循 Git 忽略规则，原仓库已跟踪的忽略文件仍参与比较；不追踪符号链接、子模块内容、Git 元数据。二进制只显示状态。不联网，不运行项目 hooks、filter、textconv 或自定义 diff 驱动。

为控制耗时，每次采集最多 5 秒、4000 个文件、单文件 2 MiB、总内容 32 MiB，Git 枚举输出最多 512 KiB；受限时明确标记不完整或本轮不可用。差异预览最多 48000 字节、1000 行，每行 2000 字符。变更按文件树逐层、分页加载，点击在当前 Widget 查看 diff，返回后恢复文件树。复用 Git Widget 的图标、按钮和只读右键菜单；不显示提交图。所有 Git 操作在独立工作进程执行。只保留一份完成结果，不提供历史；并行任务仅在运行时保留各自起始基线（最多 8 个），完成时释放或替换。刷新会清理旧版本的 Git 对象；退出或停用清理全部临时快照，重新启动不恢复，崩溃遗留在下次启用时清理。不提供暂存、放弃、提交或自动回滚。

依赖系统 Git。Git 缺失时显示安装提示，不阻碍 Agent 正常工作。开启时若任务已开始，则从下一轮开始建立基线。关闭应用本身会停止服务，不能保证为强制结束整个应用生成最终快照。

空白时仅显示“暂无变更”和刷新。说明与受限状态收在问号提示中。页面组件直接复用相邻的官方 git-viewer 包，SDK 示例应保持两个示例目录的相邻结构。
