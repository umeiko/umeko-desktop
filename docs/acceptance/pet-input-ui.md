# 桌宠输入栏 UI 独立改进

关联 #150，基于维护者 #154 / #156 的悬浮全局助手与双击胶囊，不改变默认发送目标、权限、人设或消息语义。

现有输入栏缺少明确的聚焦层级，普通冒泡与输入栏同时出现会增加视觉负担；靠近屏幕边缘时也需要避免遮挡重要通知。本补丁采用细蓝色描边和蓝色发送箭头，未聚焦时减淡，输入时突出。输入栏在宠物上方，普通冒泡避让输入，但提醒和助手通知优先；没有足够空间时暂时隐藏输入并保留草稿。聊天记录与运行详情仍在 Desktop，不增加桌宠历史面板或快捷键说明行。

本 PR 仅包含输入栏外观与布局、相应测试及真实截图。项目和定时任务入口是另一独立 PR。

## 验证范围

用户已查看实际运行截图并明确验收，授权分批提交。截图来自 Linux Qt offscreen 的实际应用，不是设计稿；本地 Pi fixture 验证真实桥接链路，不调用远程模型。Windows 原生 IME、焦点、多屏和 DPI 尚未实机验证。未执行发布或合并。
