Optional Linux x64 Qt WebEngine component for the Python and C++ editions of Umeko Desktop using Qt 6.10.2. This resource release is separate from application updates.

Download the ZIP and give its local path to the Umeko Agent. The Agent's earlier URL submission returned the exact SHA-256, destination and activation JSON for your installation. The Agent verifies and extracts the ZIP with its existing tools; system Qt stays as it is and no administrator permission is needed. Restart Umeko at a convenient time after installation and ask the Agent to submit the URL again.

If GitHub is unreachable, download this same ZIP on another network or device and transfer it locally. Keep the original file and verify its SHA-256. Use this exact ZIP, which matches Qt 6.10.2 on Linux x64.

The component includes Qt/Chromium runtime files and their license information under `licenses/Qt-SBOM/`. Windows and macOS use their native Qt WebView backends and need only the regular app.
