Optional Linux x64 Qt WebEngine component for the Python and C++ editions of Umeko Desktop using Qt 6.10.2. This resource release is separate from application updates.

Download the ZIP and give its local path to the Umeko Agent. Its failed URL submission contains the exact SHA-256, destination and activation JSON for your installation. The Agent can verify and extract it with its existing tools; no system Qt replacement or administrator permission is needed. Restart Umeko at a convenient time after installation and ask the Agent to submit the URL again.

If GitHub is inaccessible, download this same ZIP on another network or device and transfer it locally. Keep the original file and verify its SHA-256. Do not substitute a ZIP for another Qt version or architecture.

The component includes Qt/Chromium runtime files and their license information under `licenses/Qt-SBOM/`. Windows and macOS use their native Qt WebView backends and do not need this Linux package.
