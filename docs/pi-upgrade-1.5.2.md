# Bundled Pi 1.5.2

The factory runtime is pinned to `@earendil-works/pi-coding-agent@1.5.2`,
upgraded from 1.3.0. The lockfile pins the corresponding Pi packages, including
the new `pi-schema` validator. The runtime lives in `runtime/releases/coding-1.5.2`;
factory reset, search tools, ACP dependency resolution and release packaging use
the same directory and version. The bundled Node 22.23.3 satisfies Pi's Node
22.19.0 minimum. Existing user profiles and independently installed kernels are
preserved.

Upstream release and API references:

- https://github.com/earendil-works/pi/releases/tag/v1.5.2
- https://github.com/earendil-works/pi/blob/v1.5.2/packages/coding-agent/CHANGELOG.md

## Compatibility boundaries

Pi 1.5 uses JSON Schema validation for tool arguments. TypeBox refinements and
other features outside JSON Schema no longer validate arguments. Umeko's built-in
tool schemas use JSON Schema-compatible fields. Pi 1.5.1 also changes grep context
handling and omits an empty `tools` array for compatible model endpoints. These
upstream changes remain intact.

Umeko retains its explicit-provider projection, diagnostic retry adaptation and
`cacheWarming: "off"` session setting. The upgrade does not enable Pi's new default
idle cache warming or add public model accounts to the desktop.

`tests/pi-upgrade.test.mjs` verifies the actual installed dependency family and
continues a synthetic session generated by the real Pi 1.3.0 SDK. Its persisted
tool results, compaction boundary, model, thinking level and existing entries must
survive unchanged. Existing bridge suites additionally cover real tool execution,
permissions, compaction, history, Skills, extensions, subagents, MCP and transport.

Local acceptance checks cover Linux. Windows and macOS packaging remain subject
to their respective CI builds after user acceptance.
