# 扩展详情与更新检查

在设置 → Agent → Pi 配置 → Pi 扩展中点击扩展名称，打开详情。详情显示本机实际安装包的版本、描述、主页、源代码仓库和 npm 链接；没有声明的链接不会猜测生成。扫描只读取清单，不导入或执行扩展代码。

工具列表来自当前 Pi 实例的工具注册表，按扩展来源路径匹配，显示工具名称及其功能说明。未加载、已停用或只提供命令/界面的扩展可能没有已加载工具；启用后刷新可以同步当前实例。列表使用虚拟化视图，较长说明可滚动和复制。

更新检查仅在用户点击时发生：

- npm 扩展查询软件源的最新正式版本，并与本机版本按 semver 比较。使用当前 npm 源、`.npmrc`、CA 证书和代理配置，有超时限制；检查不会安装或替换包。
- Git 扩展比较所在分支与 `origin` 的提交，不拉取或切换工作树。
- Pi 内置扩展跟随内核更新；Umeko 自身扩展通过软件更新入口检查。
- 随 Umeko 集成的社区扩展仍显示真实包名、社区来源和版本。检查可以发现上游新版本，实际升级由 Umeko 适配后随软件交付。
- 普通本地文件没有可确定的更新源时，明确显示该状态。

工具目录的数量与可见列表使用同一份数据。列表显式绑定滚动视口的宽高，避免出现“数量非零但行为空白”的情况；界面回归同时检查行的尺寸、位置和可见性。
