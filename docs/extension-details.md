# 扩展详情与更新检查

在设置 → Agent → Pi 配置 → Pi 扩展中点击扩展名称，打开详情。详情显示本机实际安装包的版本、描述、主页、源代码仓库和 npm 链接，链接以扩展自己声明的为准。扫描只读取清单文件，扩展代码不会运行。

工具列表来自当前 Pi 实例的工具注册表，按扩展来源路径匹配，显示工具名称及其功能说明。未加载、已停用或只提供命令/界面的扩展可能没有已加载工具；启用后刷新即可同步当前实例。较长的说明可滚动和复制。

更新检查在用户点击时进行：

- npm 扩展查询软件源的最新正式版本，并与本机版本按 semver 比较。使用当前 npm 源、`.npmrc`、CA 证书和代理配置，有超时限制。检查只查询版本，已安装的包保持不变。
- Git 扩展比较所在分支与 `origin` 的提交，工作树保持不变。
- Pi 内置扩展跟随内核更新；Umeko 自身扩展通过软件更新入口检查。
- 随 Umeko 集成的社区扩展显示真实包名、社区来源和版本。检查可以发现上游新版本，升级版本由 Umeko 适配后随软件更新提供。
- 没有可确定更新源的本地文件会显示相应状态。

工具目录的数量与可见列表使用同一份数据。
