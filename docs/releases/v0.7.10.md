# Umeko 0.7.10

- 新增实验版 **Umeko CLI 与 ACP v1**。可以从源码启动终端聊天，和桌面共享模型配置与 Pi 会话。支持 ACP 的编辑器可通过 stdio 接入 Umeko，发送文本、恢复会话、切换模型和处理审批。内置帮助新增启动示例、支持范围和排查步骤。[CLI 与 ACP 指南](https://github.com/umeiko/umeko-desktop/blob/main/runtime/umeko-docs/cli-acp.md)
- Windows 新增可选的 Agent 命令沙箱，覆盖 Bash、PowerShell、后台任务和本地 MCP。沙箱默认关闭，可在 Agent 设置中配置，命令继续沿用审批规则。[#213](https://github.com/umeiko/umeko-desktop/pull/213)
- 新增自动 Git 工作树设置。启用后，适用的子智能体和 Agent Bus 写入任务可在独立工作树中工作。请求卡显示分支及目录，发生合并冲突时保留对应改动，便于检查和处理。[#224](https://github.com/umeiko/umeko-desktop/pull/224)
- 模型思考检测会比较实际思考量和答题结果，分别判断思考开关与档位是否有效。设置里可查看测量结果，也可保留手动配置。[#234](https://github.com/umeiko/umeko-desktop/pull/234)
- 更新 Cowork 总览与模式切换，支持配置默认工作目录。图片、语音和视频生成可分别选用已配置的供应商账号和模型。
- Windows 新增默认关闭的**图形兼容模式**，用于排查桌宠开启或锁屏恢复后的窗口卡死。在「设置 → Agent → Umeko Desktop」切换，从托盘完全退出并重启后生效。[#204](https://github.com/umeiko/umeko-desktop/pull/204)
- 改进内置 Widget 的中英文显示与 Skill 导入失败时的提示，修复工作区选择器读取默认目录时的问题。
