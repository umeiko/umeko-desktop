# Umeko 0.7.12

macOS Intel 安装包随 `0.x.0` 版本发布。Intel Mac 可继续使用 [0.7.10 安装包](https://github.com/umeiko/umeko-desktop/releases/download/v0.7.10/Umeko-0.7.10-macos-x64-bc3aa47.dmg)。

- **多模态设置。** 在「设置 → 账号与供应商 → 多模态模型选项」分别配置图像理解、图像生成、语音生成和视频生成。生成页顶部可选默认模型，下方可管理供应商、增删模型和导入 Provider ZIP。图像理解沿用聊天供应商的视觉模型。 [#265](https://github.com/umeiko/umeko-desktop/pull/265)
- **聊天内播放音频。** 语音生成结果和已提交的本地音频可在聊天卡片中播放、拖动进度和调节音量。图像和语音生成期间会显示状态卡。 [#259](https://github.com/umeiko/umeko-desktop/pull/259)
- **Windows 沙箱。** 修复项目搜索和 Git Bash 的运行时读取，并恢复前台命令的输入与输出。 [#255](https://github.com/umeiko/umeko-desktop/pull/255) · [#257](https://github.com/umeiko/umeko-desktop/pull/257)
