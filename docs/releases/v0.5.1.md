# Umeko Desktop v0.5.1

## 中文

- 供应商新增、编辑共用独立浮窗，打开与关闭使用 PID 动画；调整窗口与字体大小后仍可滚动填写和保存。
- 供应商网络设置支持额外的 PEM CA 文件，保留系统证书与域名校验；证书错误显示底层原因与请求详情，并停止无效的网络重试。
- 输入框支持 Alt+Enter 和 Shift+Enter 换行，Enter 继续用于发送。
- 超过三分钟的 Agent 任务结束后，即使应用在前台也会提示；后台短任务保留原有通知行为。收起到后台的提示改为第一人称。
- API 代理启用时才在侧栏显示运行状态；项目与会话右键菜单根据文字宽度布局，并改进窄窗口下的换行与定位。
- 重绘 Pin 图标，统一启动入口与开发工具命名。
- `config_umeko` 新增 `providers.certificate`，可按供应商设置或清除 CA 文件；网络与证书帮助按需加载。

证书设置在供应商齿轮 →「网络设置」中。配置保存后下一次请求生效；通过环境变量设置 `UMEKO_MODEL_CA_FILE` 或 `NODE_EXTRA_CA_CERTS` 后须完全重启应用。模型请求证书与 npm、客户端更新下载证书分别管理。

## English

- Add and edit providers in a shared floating dialog with PID opening and closing animations, a scrollable form, and accessible save controls at larger font sizes.
- Configure a provider-specific PEM CA file while retaining system trust and hostname verification. Certificate failures expose their underlying cause and request details without entering network retry loops.
- Use Alt+Enter or Shift+Enter for a new line; Enter still sends the message.
- Receive a notification when an Agent task takes longer than three minutes, including while the app is visible. Existing background notifications remain available for shorter tasks, with updated first-person tray wording.
- Show sidebar API proxy status only while running. Fit project and conversation context menus to their labels and viewport, with a clearer Pin icon.
- Use `config_umeko` operation `providers.certificate` to set or clear a provider CA file; certificate and network documentation remains available on demand.

Find certificate settings under the provider gear → Network settings. Saved file settings apply to the next request. Restart the application after changing `UMEKO_MODEL_CA_FILE` or `NODE_EXTRA_CA_CERTS` in the environment. Model, npm, and application-update certificate settings are managed separately.
