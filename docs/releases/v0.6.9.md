# Umeko 0.6.9

- **加快长会话切换**：最近三个会话保留控件、文本排版和滚动位置；冷会话在后台读取，正文按可见区域逐步创建。未改变的凭据不再随切换反复写入系统密钥环。
- **减少滚动卡顿和加载停滞**：优先补齐所有可见消息，滚动停止和排版变化后继续加载。控件按约 1.5 屏范围创建，边缘文本使用有界缓存，避免底部消息反复出现加载占位。
- **修复侧栏选中框闪动**：列表刷新时保持正确的选中位置，动画不再跳到顶部；动画与正文加载独立推进。
- **完善会话内核缓存**：支持设置空闲 Pi 内核缓存数量；回收可重建资源时保留历史、草稿和浏览位置，并复用运行中内核读取插件目录。
- **改进 Skill 使用说明**：补充受限网络下的依赖安装、CI 排查及文档处理指引。
- **加强性能回归**：覆盖快速连点切换、连续反向滚动、静止后加载完成、边缘稳定性，以及 6000 条消息的跳转、复制和缓存恢复。

本次为 Python 桌面版补丁更新，提供 Windows x64、macOS Apple Silicon、macOS Intel 和 Linux x64 安装包。
