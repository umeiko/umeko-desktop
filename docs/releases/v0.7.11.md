# Umeko 0.7.11

macOS Intel 安装包随 `0.x.0` 版本发布。Intel Mac 可继续使用 [0.7.10 安装包](https://github.com/umeiko/umeko-desktop/releases/download/v0.7.10/Umeko-0.7.10-macos-x64-bc3aa47.dmg)。

- **流式读取超时后自动接续。** 客户端在同一会话中依次等待 5、10、30 秒，最多发送三次 `continue`，保留已完成的工具结果。重试和接续提示显示在聊天活动中，恢复后自动收起。三次都失败时显示最终错误和请求详情。供应商网络设置支持调整流式空闲超时，详情记录响应头、首条 SSE 事件、最后收到数据的时间、总耗时和结束状态。[#256](https://github.com/umeiko/umeko-desktop/pull/256)
- **打包版 CLI 与 ACP。** Windows 提供 `Umeko-cli.exe`，macOS 与 Linux 提供 `umeko` 启动器。可在「设置 → Agent → Umeko Desktop」最下方一键配置当前用户的 PATH。内置文档包含三平台的手动配置和 ACP 接入方式。[#244](https://github.com/umeiko/umeko-desktop/pull/244) · [CLI 与 ACP 指南](https://github.com/umeiko/umeko-desktop/blob/main/runtime/umeko-docs/cli-acp.md)
- **聊天外观与 Markdown 预览。** 新增聊天壁纸及位置编辑器。修复长 Markdown 中滚动返回后表格留白和代码块渲染错误。[#241](https://github.com/umeiko/umeko-desktop/pull/241) · [#244](https://github.com/umeiko/umeko-desktop/pull/244)
- **全局子智能体群聊。** 在同一个 Widget 中查看成员、协作消息和任务进展，使用 @ 提到指定成员，并修复群聊回复工具的作用范围和键盘选择。[#243](https://github.com/umeiko/umeko-desktop/pull/243) · [#247](https://github.com/umeiko/umeko-desktop/pull/247)
- **Cowork 启动与产物预览。** 首页可直接输入任务或拖入附件，使用 Ctrl+K 查找能力和最近会话。点击文件卡可预览产物，XLSX 支持只读预览首张工作表。快速 OCR 可在工作区部署本地 CPU 识别环境，由 Skill 读取原图并在会话中返回结果。[#248](https://github.com/umeiko/umeko-desktop/pull/248) · [#242](https://github.com/umeiko/umeko-desktop/pull/242)
- **Windows 命令输出。** 本地 Pi PowerShell 工具和后台任务可为单次命令指定 GBK 编码，默认仍使用 UTF-8。[#246](https://github.com/umeiko/umeko-desktop/pull/246)
- 内置指南增加图片和语音供应商 ZIP 的配置流程，说明如何导入插件、配置凭据并选用模型。
