# Umeko 0.6.6

- 优化超长会话的打开与历史浏览：围绕保存的阅读位置优先加载可见内容，再准备相邻消息；历史 Markdown 在后台处理并缓存。快速跳转会替换过时的加载请求，补充内容时保持当前消息的位置。
- 大型 Markdown 预览改为按可见区域显示，保留完整表格、代码块和全文；支持跨段选择、复制、源码切换与缓存重开，减少大文档对界面响应的影响。
- 稳定流式思考文字的行距，减少输出时的高度变化与滚动跳动；浏览上方内容时保持阅读位置。
- 含大量图片的对话默认只向模型发送最近的至多 3 张图片。较早图片在请求中替换为可重新读取的文件引用，聊天记录中的原图仍保留。主会话与子智能体均支持此策略，可通过 Agent 配置调整图片数量。
- 文件管理器顶部新增双击行为选择：**预览 / 用默认 App 打开 / 附加到聊天**，默认沿用附加到聊天。选择自动保存并即时应用，保留已展开的目录和当前位置。
- 设置 → Agent → Umeko Desktop 新增 **聊天区域左右展开提示** 开关。关闭后，两侧悬浮提示立即隐藏，当前聊天宽度保持不变；重新开启后可继续展开或收起。
- 会话分支采用独立的分流图标，与 Git 分支图标区分。

本次为 Python 桌面版更新，提供 Windows x64、macOS Apple Silicon、macOS Intel 和 Linux x64 安装包。
