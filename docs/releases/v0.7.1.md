# Umeko 0.7.1

- **看清 Preview 安装前需要准备什么**：每项安装条件都显示是否通过，并用中文和英文说明解决方法；处理后可点击按钮重新检查。
- **改进 Preview 安装的网络连接**：先尝试代理，失败后尝试直连；安装和下载共用证书配置，连接失败时按五类原因提供处理提示，并保留用户已有的 pip、npm、git 证书、验证和镜像设置。
- **自动识别模型的思考设置**：自动检测可用的思考档位和关闭方式，在添加或刷新模型、打开模型选择框或设置、手动重新检测时更新结果；发送消息时不会触发检测。
- **让应用插件独立处理任务**：应用插件可使用由 Umeko 管理的独立会话，提交任务、接收进度、等待结果、取消任务、查看历史和处理审批，并可在设置文件中配置会话。
- **减少长会话底部跳动**：保留已测量的消息高度，减少大量思考内容和工具调用造成的上下跳动；聊天记录按约 2.5 屏分组加载，排版完成后再显示，向上滚动时不再出现加载占位或内容移位。
- **修正生成中发送引导消息后的状态**：任务继续运行时不再误显示“正在停止”或“已停止”，正常结束后显示“已完成”。
- **修复辅助看图后的 HTTP 400 错误**：修复辅助看图等工具调用后，部分供应商接口因工具调用消息缺少正文而返回 HTTP 400 的问题。
- **加快含失败响应的长会话加载**：会话里有很大的失败响应时，打开会话不再重复处理完整的原始错误内容；含 6,000 条消息和一条 8 MB 错误的会话，首次打开从约 14 秒降到 1 秒以内。原始聊天记录不变，升级后第一次打开旧会话会重建一次缓存。
- **新增纯白主题，可以不启用角色**：新增蓝白「纯白」主题，并作为新安装的默认主题；原来的浅色主题改名为「草绿」，已选择的主题不变。在主角色选择中勾选「不启用」，即可使用简洁机器人、普通系统提示和箭头控件，原有角色设置会保留。应用图标改为几何机器人。

本次优先提供 Windows x64。其他平台仅在同版本构建通过验证后提供；历史版本的其他平台包仍保留在 Releases 中。
