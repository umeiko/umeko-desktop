# Umeko 0.7.2

- **子智能体复用主聊天界面**：普通子智能体和全局子智能体共用主聊天的消息渲染、历史加载、视口分区与缓存，保留代码块、工具结果、文字选择及切换后的阅读位置。
- **查看和压缩各自的上下文**：子智能体聊天新增与主聊天一致的上下文用量圈和手动压缩入口，操作作用于当前选中的子智能体；问题导航列表可直接跳转到历史提问。
- **限制全局子智能体的历史展示窗口**：展示最近一个完整压缩区间及当前新消息，只有成功压缩才推进窗口，原始会话文件继续保留。
- **修正打开运行中会话时的消息衔接**：历史加载期间保留实时消息前缀与后续增量，避免丢失或重复内容；恢复阅读位置时等待临时重置的非空模型完成加载。
- **新增可选 DeepSeek Harness 后端（实验版）**：通过官方 ACP 接入，可复用 Umeko 的模型代理或使用独立配置，提供审批详情、停止状态与运行时设置；后端选择使用 Pi 和鲸鱼图标，并标注实验版。
- **按来源管理系统提示词**：内置 Widget 按 Pi、Skills、Umeko、项目指令和扩展等来源分组，支持按工作区启停或编辑覆盖内容，并展示生效差异；原始文件保留。
- **任务记录移入独立 Widget**：按需启用任务记录，查看目标、执行尝试、文件交付与验收过程。
- **改进更新清理和 Windows 输入法**：新版本成功启动后清理旧包和程序备份，保留近期或仍在使用的临时下载；Windows 候选窗口跟随当前输入光标。

本次优先提供 Windows x64。其他平台仅在同版本构建通过验证后提供；历史版本的其他平台包仍保留在 Releases 中。

**0.7.1 作为里程碑版本继续保留**，其标签、Release 和下载资产不会随本次发布清理。
