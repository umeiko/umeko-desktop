# Umeko Desktop v0.5.2

## 中文

- `config_umeko` 的后台管理操作返回任务 ID，可查询排队、执行中、完成和失败状态，以及实际完成结果；避免把已提交误报为已完成。
- 统一供应商与模型映射的校验。同一个上游模型可使用不同别名，并保留各别名的视觉能力、上下文长度等配置；保存失败会返回明确原因。
- 配置查询保留插件认证字段的名称和说明，继续隐藏敏感值；混用账号 ID 和插件包 ID 时提供具体的参数指引。
- 内核检查或更新期间暂时不能发送消息时，显示原因，并通过 `status.get` 提供给 Agent。
- 修复最大化窗口拖动还原后的状态与缩放交互。网页预览保留聊天区的可用宽度，空间不足时临时收起左侧栏，关闭预览后恢复。
- 网页预览为窗口边缘和分隔拖动条留出操作区域；关闭模型/供应商选择小窗后立即恢复输入框焦点，可以直接继续打字。

## English

- Return job IDs for asynchronous `config_umeko` management operations. Query queued, running, done and failed states together with actual completion results instead of treating acceptance as completion.
- Share provider/model-mapping validation. Distinct aliases can refer to the same upstream model while retaining their own vision and context-window settings. Rejected edits return explicit errors.
- Preserve plugin authentication field names and descriptions in configuration queries while redacting secret values. Explain account IDs versus installed package IDs in argument errors.
- Explain why messages cannot be sent during a kernel check or update, and expose the reason through `status.get`.
- Restore maximized windows through Qt before starting a title-bar drag. Keep the chat usable beside previews, temporarily collapsing the sidebar when necessary and restoring its layout afterward.
- Reserve native-browser margins for window resizing and the pane splitter. Restore typing focus immediately after dismissing the provider/model selector.
