# Umeko 0.6.7

- **统一多模态设置**：图片理解、图片生成、语音生成和视频生成集中在“设置 → 账号与供应商 → 多模态模型选项”二级页，复用已有供应商账号、凭据、代理和 CA 配置。
- **辅助视觉与 `analyze_image`**：主模型不支持图片时，可选择辅助视觉模型，并独立设置自动分析附图、按需识图工具。首次观察随会话保存，后续追问与重启后复用；新增附图只分析新图片。原生视觉主模型仍直接接收原图。
- **清晰的识图过程**：自动和按需识图统一显示在聊天工具卡片中，直接展示实际模型名；展开可查看供应商、结果及错误。输入框上方不再额外显示识图提示，原图仍保留在聊天历史中。
- **图片与语音生成**：新增 `image_gen`、`voice_gen`，支持选择已有账号及目录中的模型或手填模型 ID，配置默认尺寸、质量、数量、音色、格式和语速。调用确认后将结果保存到当前工作区，避免覆盖同名文件；聊天展示可恢复的图片、音频卡片，不自动打开或播放。上游服务需支持对应生成接口与参数。
- **异步视频生成**：新增 `video_gen`，支持配置模型、时长与分辨率，在工具卡片中显示排队、生成进度与错误；停止时取消等待、丢弃后续结果并尽力清理远端任务。完成的 MP4 保存到工作区，避免覆盖同名文件，并保留历史文件卡片。
- **代码检查点时间线**：变更查看器按轮次展示代码检查点，支持查看差异与恢复代码；恢复与后台命令协调，恢复期间阻止新建后台任务。
- **正式版与预览版通道**：可从正式安装包启用官方 main 源码预览版，并切回保留的正式版。
- **豆包角色与桌宠**：新增豆包主角色、子智能体形象和桌宠动画，可独立选择角色与桌宠形象。
- **交互修复**：供应商登录支持取消，改善输入法候选窗随光标、焦点及滚动更新的位置。

视频生成需要供应商提供兼容接口；应用重启后，进行中的视频任务需要重新发起。图片、音频和视频由用户点击后打开或播放。

本次为 Python 桌面版正式更新，提供 Windows x64、macOS Apple Silicon、macOS Intel 和 Linux x64 安装包。
