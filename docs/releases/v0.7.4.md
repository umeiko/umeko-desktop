# Umeko 0.7.4

- **双击桌宠直接派活**：已绑定全局子智能体时，双击桌宠即可打开单行任务输入框；回车或点击内嵌发送按钮，将任务交给当前绑定的悬浮小助手。忙碌时沿用其消息队列，不切换当前聊天。未绑定时不弹出输入框。
- **简洁的胶囊形输入框**：无占位文本，随 Umeko 主题和字号变化，圆形发送按钮与右端半圆同心，弹出和收起复用现有 PID 动画。支持中文输入法、Esc 和点击框外收起，发送失败保留草稿；隐藏桌宠或断开绑定时收起输入框。
- **悬浮小助手与人物设定**：桌宠可绑定独立全局子智能体，通过受限的简短气泡报告长任务结果；不同桌宠形象保留各自的人物设定。透明区域不阻挡桌面鼠标操作。
- **全局子智能体独立 Skills 设置**：为各个全局子智能体分别选择可用技能，与普通聊天的技能设置分开管理。
- **更新桌宠动画**：八奈见、小鞠、马剃天爱星和豆包换用交付的透明循环 GIF，保留任务状态、稀有待机和互动台词；桌宠右键菜单统一跟随应用主题。
- **模型与请求配置改进**：支持配置模型请求头，运行中调整插件会话模型，并保留外部修改的 settings.json。修正子智能体报告唤起后主会话的运行状态。
- **定时任务修补**：共享全局计时器，按系统本地时区显示时间，并补足 Windows 时区数据和调度进程退出清理。

提供 Windows x64、Linux x64、macOS Apple Silicon 与 macOS Intel 下载包；各平台构建、应用启动和 Pi 内核校验通过后发布。

**0.7.1 里程碑版本继续保留。**
