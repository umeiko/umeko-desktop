# Umeko Desktop v0.4.0

- Install verified updates with a separate Yanami installer: confirm stopping agents, watch installation progress, then restart the new version. Failed replacements keep a recovery path.
- Keep agents running when closing the main window. Restore or quit from the Yanami tray icon, and receive native task-completion notifications while the app is hidden or minimized.
- Add Claude Code, Codex, Kimi Code, DeepSeek, GLM Coding Plan and MiniMax subscriptions with a Key and optional account alias. GLM and MiniMax include a website-and-region dropdown, with separate official Key links and account credentials.
- Use the OpenAI Responses API for Codex, including streaming, tools, images and conversation history.
- Configure proxy model aliases inside provider submenus. Copy protocol Base URLs directly; LAN mode selects the computer’s network IP automatically.
- Install macOS builds by opening the DMG and dragging the app into Applications. ZIP archives remain available for automatic updates.
- Fix Linux Chinese input by compiling the pinned Fcitx5 plugin against the application’s bundled Qt 6.10.2, avoiding incompatible system Qt plugins.
- The Python edition supports a local font selector and persisted text scaling from 30% to 200%.
- Keep bundled npm launchers working when portable installations are copied without symbolic links.
