# Umeko 0.7.7

- 图片生成增加火山方舟、阿里云百炼和 OpenAI 兼容自定义供应商。预设提供平台 Logo、官方 API Key 申请链接和独立的模型选择；自定义服务可配置名称、Base URL、API Key 和模型 ID，并支持多个账号。
- 内置适配 Seedream 5.5、5.0 Pro、5.0 Flash、5.0 Lite、4.5、4.0，以及 Qwen Image 3.0 Pro、3.0、2.1 Pro、2.1 Turbo。按型号校验图片数量、尺寸、比例和格式，生成结果保存到项目并显示在聊天中。
- 改善会话加载与长历史滚动：优先准备可见消息、按需创建富文本控件并限制离屏资源，保留近期会话布局和浏览位置。
- 修复设置开关更新时遍历整份历史配置造成的卡顿，避免图片供应商配置覆盖未保存的语音、视频输入。
- 包含工作区默认路径升级后的历史会话恢复、生成期间模型选择、OpenAI 兼容参数与响应处理，以及 Bash 停止和超时收尾等修复。

图片生成需要对应供应商的 API Key 和模型权限，每次调用前会显示确认。预设目录是本版已适配的模型，并非平台全部型号。
