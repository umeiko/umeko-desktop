# Umeko Desktop v0.6.0

## 中文

- 完整接入社区 Pi 子代理：在聊天中查看任务卡片、运行状态和独立对话，在右侧继续交流；默认不再限制为 4 个，重复角色用序号区分。一次启动超过 4 个时折叠为集合入口，通过可滚动矩阵选择具体任务。
- 子代理输入与主聊天共用队列逻辑：Enter 排队，Ctrl+S 立即打断并优先介入；待发送消息显示在对应输入框上方，支持编辑、删除和引导，附件及草稿独立保存。
- 子代理支持拖入文件和图片，显示对应角色的接取形象；完成回复后可点击角色头像互动。运行中的工具使用中性沙漏标识，避免误认为执行失败。
- 统一模型选择、子代理列表和任务矩阵的 PID 弹出动画，修复模型选择失效、任务摘要溢出及窄窗和大字体下的布局问题。
- 侧栏拖动支持松手后吸附收起，反向拖回可取消；预览栏达到最小聊天宽度后提供角色提示。统一主聊天与子代理头像尺寸。
- 为子代理补充按需向主智能体汇报的简短提示。手动指定模型出错时，直接返回当前可用模型及正确调用名称，减少反复试错。
- 文档预览支持源码与渲染视图切换；工具目录和扩展详情提供可读的展示。网络失败识别保留结构化 TLS 错误信息，子代理继承主程序的重试设置。
- 保留社区 Pi 原生会话、工具和恢复机制；子代理缓存存储在用户目录，避免写入已签名应用包。

## English

- Integrate community Pi subagents with task cards, live status and separate conversations in the side pane. Remove the default four-agent limit and number repeated characters. Groups larger than four collapse into a scrollable task matrix.
- Share the main chat input queue with subagents: Enter queues a follow-up; Ctrl+S interrupts the current run and prioritizes the new input. Pending messages appear above each composer with edit, delete and steer actions. Drafts and attachments remain isolated per conversation.
- Drop files and images into subagent chats with character-specific drop artwork. Completed replies include interactive character portraits. Running tools use a neutral hourglass instead of an error indicator.
- Reuse PID popup motion for model selection, subagent lists and task matrices. Fix model selection, overflowing summaries and layouts in narrow panes or at large font sizes.
- Collapse side panes after releasing a drag past the threshold, with reversal available before release. Show character feedback at the minimum chat width and match portrait sizes across parent and child chats.
- Add a brief completion-reporting hint for subagents. Invalid explicit model selections return the currently available models and canonical invocation names.
- Switch document previews between source and rendered views, and show readable tool catalogs and extension details. Preserve structured TLS failure classification and inherit the desktop retry policy in child sessions.
- Keep community Pi session, tool and resume behavior. Store subagent caches in the user directory rather than inside signed application bundles.
