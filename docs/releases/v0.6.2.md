# Umeko Desktop v0.6.2

## 中文

- 新增全局子智能体 Widget：跨工作区保留独立上下文，支持创建、管理、停止和继续对话，复用主聊天的头像、思考折叠、工具过程和代码渲染。
- Agent 可以请求创建全局子智能体，默认打开预填表单由用户确认；开启「允许自动被创建」后直接创建。名称可留空，使用人物名并自动编号；未指定形象时随机选择。
- 智能体总线按「会话 ↔ 全局子智能体」分别授权，支持双向派发和结果回传。项目树中的会话进入二级列表后逐项勾选，创建者会话自动连接新智能体。
- 普通会话只发现已连接的全局子智能体，并可查看空闲、忙碌时长和排队情况。全局子智能体能查看和管理自己的连接；宿主绑定真实身份，避免混淆或冒用其他智能体。
- 忙碌时按队列处理消息，复用主聊天的队列组件，支持查看完整内容、优先处理和删除待处理项。修复发送消息时的重复显示，并完善创建工具的参数说明、重试和错误反馈。
- Pi 扩展与 MCP 管理迁入可关闭的 Widget，保留安装、详情、配置和资源浏览能力；补齐 Widget 宿主通信与共享聊天、队列组件。

## English

- Add an application-lifetime Global Subagents Widget with persistent contexts, creation, management, stopping and continued conversations. Reuse the main chat renderer for avatars, collapsible thinking, tool activity and code.
- Let Agents propose fully prefilled global-subagent creation forms for user approval, or create directly when the user enables automatic creation. Optional names use numbered character names; omitted appearances are selected randomly.
- Authorize each conversation-to-global-subagent pair separately on Agent Bus, with bidirectional dispatch and correlated results. Open a conversation in the project tree to select its connections. Successful model-requested creation automatically connects its originating conversation.
- Limit ordinary conversation discovery to connected global subagents and expose idle/busy duration and queue counts. Global subagents can inspect and manage their own connections, while native caller identity prevents impersonation.
- Serialize incoming work and reuse the main chat queue for full-message inspection, priority and removal. Fix duplicate pending user messages and improve creation arguments, retries and actionable errors.
- Move Pi extension and MCP management into a closeable Widget, retaining installation, details, configuration and resource browsing. Extend Widget host communication and shared chat/queue components.
