# Umeko 0.7.9

- 新增实验版 Cowork。每个 Coworker 可绑定工作目录，按角色选择工具、Skill、MCP 和子智能体。角色编辑器会截断过长的工具说明，可以单独授权「管理 Umeko」，包括内嵌 Pi 命令。
- 终端 Widget 默认开启，Widget 市场默认关闭。已保存的开关选择会保留。
- Cowork、团队协作和远程工作区均默认关闭，可在「设置 → Agent → Umeko Desktop」中启用。团队成员选模移到团队协作设置，模型组移到多模态模型选项下方。
- 远程工作区支持通过 SSH 运行命令和访问文件，连接中断后可自动重连。远端网络受限时，可使用本机网络转发。
- 支持命令审批前缀和转入后台的 Bash、PowerShell 命令。Pi 管理命令统一通过 `umeko_desktop` 的 `pi.run` 使用。
- 加入大图输入预处理和上下文超限回退。遇到超限时，可用去除历史图片数据的上下文重试，保留文本和工具记录。
- 修复文档预览切换时的加载竞态、macOS 包的供应商 TLS 信任，以及部分 OpenAI 兼容供应商流式响应提前结束的问题。
