# Umeko 0.7.14

macOS Intel 安装包随 `0.x.0` 版本发布。Intel Mac 可继续使用 [0.7.10 安装包](https://github.com/umeiko/umeko-desktop/releases/download/v0.7.10/Umeko-0.7.10-macos-x64-bc3aa47.dmg)。

- **Windows 安装包瘦身。** 缩小 x64 下载包。Windows 沙箱首次运行 Bash 时单独下载并校验兼容组件。在「设置 → Agent → Umeko Desktop」可以自动查找或手动指定普通 Bash 使用的 Git for Windows。[#273](https://github.com/umeiko/umeko-desktop/pull/273)
- **语音生成音色下拉。** 在「设置 → 账号与供应商 → 多模态模型选项」里选择供应商提供的音色。支持继续使用已保存的音色 ID，也可以给旧版供应商手动填写 ID。[#274](https://github.com/umeiko/umeko-desktop/pull/274)
- **通用 IM 机器人 Widget。** 指定应用级插件可在后台调用已有全局智能体，发起、查询和取消回合。派发沿用智能体配置的模型、工具和审批。关闭面板或切换会话后，最终回复仍关联原请求。修复了 Windows 下多个智能体并发启动时的文件写入冲突。[#272](https://github.com/umeiko/umeko-desktop/pull/272)
- **新建项目时创建本地文件夹。** 输入不存在的本地路径后，可确认创建目录并登记项目。路径出错时会保留输入，方便修正重试。[#275](https://github.com/umeiko/umeko-desktop/pull/275)
- **macOS 更新检查。** 当内置 OpenSSL 找不到默认 CA 路径时，检查更新会回退到系统证书文件，并继续验证证书链和主机名。[#269](https://github.com/umeiko/umeko-desktop/pull/269)
