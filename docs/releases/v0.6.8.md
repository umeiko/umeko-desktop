# Umeko 0.6.8

- **修复文本模型识图后的 406 错误**：在全部扩展处理完成、正式发送模型请求前检查图片内容。无视觉能力的主模型只接收文字，不再因扩展追加图片而收到不支持的多模态请求。
- **补齐自定义消息的辅助识图**：插件提供的自定义图片消息同样交给已配置的辅助视觉模型分析，主模型接收识别文字；原图仍保留在聊天记录中。
- **覆盖模型切换与子智能体**：图片检查跟随当前请求使用的模型，并覆盖新建、恢复的子智能体。原生视觉模型继续接收原图；关闭辅助识图也不会把图片发送给文本模型。
- **聊天链接与 CI 改进**：包含已合并的聊天路径/链接交互修复，以及普通代码 PR 的轻量 CI、资源变更打包检查和运行时文件原子更新。

本次为 Python 桌面版补丁更新，提供 Windows x64、macOS Apple Silicon、macOS Intel 和 Linux x64 安装包。
