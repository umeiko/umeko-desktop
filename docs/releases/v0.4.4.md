# Umeko Desktop v0.4.4

- Load long conversations through a disposable background index and viewport pages. Bound the presentation cache with LRU eviction, preserve drafts and reading positions, and update only the changed streaming tail. Original Pi transcripts, branches and Agent context remain intact.
- Split very large rendered replies into bounded sections, preserve code/table continuity when copying, and copy selections across unloaded history pages in the background.
- Fix variable-height chat scrolling and history jumps competing with hidden scrollbars. Restore visibility correctly when a new conversation starts receiving messages.
- Fix blank Windows web previews by packaging complete Qt WebView module metadata, initializing the native surface after the panel expands, and synchronizing visibility. Show a recoverable error when a page cannot load.
- Keep sidebar resizing under the pointer, collapse only after releasing a sufficiently narrow sidebar, and briefly highlight the expand button. Keep project fold controls visible.
- Prefix fork titles with `(Fork1)`, `(Fork2)`, etc. so the branch name remains visible in a narrow sidebar.
- Trust system-installed roots alongside the updater's bundled certificates, try verified direct access after a system-proxy connection fails, and report the actual route and useful certificate errors. Certificate, hostname and archive SHA-256 verification stay enabled; proxy credentials are excluded from progress and logs.

Validation includes synthetic 100,000-message indexing, a 6,000-message Qt interaction test, paging/LRU restoration, cross-page Unicode/code/table copying, native Pi integration, real loopback HTTPS/proxy handshakes, and packaged Windows browser checks. The synthetic results are local checks, not production benchmarks.
