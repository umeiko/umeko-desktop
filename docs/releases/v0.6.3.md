# Umeko Desktop v0.6.3

## 中文

- 新增会话全文搜索：点击侧栏顶部或按 Ctrl+K，支持大小写、全词、正则和项目/会话范围过滤。搜索在后台使用随应用附带的 ripgrep，可跳转到历史消息；Esc 或跳转后保留搜索，点击返回清空。
- 内置「本轮变更审查」Widget，默认关闭。在插件管理启用后，对比本轮任务开始前后的文件，完成或中止后展示只读 diff；可关闭自动展开并手动查看。采集使用独立 Git 索引，不修改项目的暂存区或历史。
- 收紧全局子智能体边界：仅普通聊天 Agent 可以申请创建全局子智能体，禁止全局子智能体递归创建；权限由宿主核验真实会话身份，开启自动创建也不会放宽限制。相关接口文档改为按需发现。
- 修复首次打开会话/项目右键菜单时出现在左上角的问题，兼容窗口缩放、字体放大和屏幕边缘定位。

## English

- Add full-text conversation search through the sidebar or Ctrl+K, with case, whole-word, regex and project/conversation filters. Bundled ripgrep searches in the background and jumps to historical messages. Esc and result navigation retain the search; Back clears it.
- Bundle the opt-in Change Review Widget. Compare files before and after each Agent task and inspect read-only diffs on completion or cancellation, with optional automatic opening. Independent Git indexes preserve the project's staging area and history.
- Enforce global-subagent creation boundaries using host-bound caller identities. Only ordinary chat Agents may request new global subagents; recursive creation remains blocked even with automatic creation enabled. Discover optional interfaces through on-demand documentation.
- Fix first-use conversation/project context menus opening at the top-left, including large fonts, resized windows and edge placement.
