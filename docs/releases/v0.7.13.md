# Umeko 0.7.13

macOS Intel 安装包随 `0.x.0` 版本发布。Intel Mac 可继续使用 [0.7.10 安装包](https://github.com/umeiko/umeko-desktop/releases/download/v0.7.10/Umeko-0.7.10-macos-x64-bc3aa47.dmg)。

- **工作区群聊。** 从项目侧栏进入群聊，添加普通 Pi 会话作为成员。可设置群备注、移出成员或 @ 指定会话。成员可以把工作进度和产物发到群里，文档与代码沿用右侧预览。再次点击群聊图标即可返回上一会话。
- **聊天交互。** 群聊搜索支持浅色和深色主题。搜索、引用和附件继续沿用 Umeko 的控件。主聊天里悬停排队消息时会显示 Ctrl+S 快捷键提示。聊天音频去掉了播放和暂停的悬浮提示，语音合成请求会提示智能体优先使用内置工具。
- **生成权限。** 图像和语音生成支持在自动模式下直接执行。询问模式会要求逐次确认。
- **Windows 进程回收。** 修复部分插件工作进程在关闭 Umeko 后仍存活的问题。[#254](https://github.com/umeiko/umeko-desktop/pull/254)
