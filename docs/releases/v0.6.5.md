# Umeko 0.6.5

- 设置 → Agent 新增 **Umeko Desktop**：可关闭提交产物后的自动预览，并选择内置网页预览或系统默认浏览器。网页链接和本地 HTML 均遵循该设置；系统浏览器模式下，启动时跳过内置 WebView 初始化。入口使用简洁的八奈见设置图标。
- 优化聊天切换：浏览历史按需读取，不立即启动 Pi；侧栏复用目录数据，切换时不重复扫描角色资源。历史内容接入避开高亮 PID 的可见运动阶段，连续选择会话时以最后一次选择为准。
- 修正浏览历史被误标“已完成”的问题。完成标签来自真实任务结束记录，保留失败、停止、未读状态及历史回复末尾的角色互动。
- 远离聊天底部时，输入框上方显示 **↓ 最新消息** 按钮，一次点击即可返回最新回复。
- 斜杠菜单保留紧凑布局，重复展开复用技能目录。后台更新保留当前可见条目、滚动位置和选中项；输入新的筛选词时从头显示。
- Skill 管理目录加载提速，支持可调整比例的上下分栏和 Markdown 预览；技能列表展示简介，内置技能简介按软件语言显示中英文。
- 文件预览增加返回入口：从 Widget 打开的预览可返回来源 Widget 并保留状态，从聊天打开的预览可直接收起。
- Pi 能力支持会话级“默认 / 极简 / 自定义”配置，可调整工具、扩展和技能；内置扩展同样可切换。修正工具组首次打开时的状态，并统一相关图标、命名和按钮缩放样式。
- 变更查看器顶部增加“自动展开”开关，无需进入设置即可调整。
- 修正会话标识刚更新时切换 Widget 开关可能写入旧会话的问题，确保技能停用设置及时应用到后续请求。
- 恢复失败回复的请求详情入口，并在供应商 HTTP 错误中保留服务器返回的具体原因，方便查看原始请求、响应及错误信息。

本次为 Python 桌面版更新，提供 Windows x64、macOS Apple Silicon、macOS Intel 和 Linux x64 安装包。
