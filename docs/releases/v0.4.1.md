# Umeko Desktop v0.4.1

- Preview delivered webpages, Markdown, highlighted source code and plain-text artifacts in one resizable side pane. First click selects the full URL; subsequent clicks position the cursor. Delivered cards can reopen previews, copy their URL or attach them to chat.
- Keep document previews responsive with bounded background reads, explicit partial-preview notices, safe plain-text/highlight fallbacks and cancellation of stale requests. Local document previews need no browser component.
- Distribute the Linux Qt WebEngine backend as a separate verified component ZIP. Download/install guidance appears only in a URL tool response when that component is missing.
- Teach the embedded Pi Agent to use `run_pi_command` for its own packages, MCP configuration, reload and compaction, and to submit user-facing artifacts after creating them. Add a scoped MCP command/JSON installer.
- Animate the project sidebar with PID motion, remove the redundant workspace label, and clear artifact hover highlights/tooltips when the pointer leaves or the user clicks elsewhere.
- Repair moved-profile project identities so duplicate workspace rows no longer leave history entries unclickable, while preserving native sessions and credentials.
