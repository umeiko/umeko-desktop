- Add `config_umeko`, one Agent tool for the running desktop's providers, model mappings and networks, provider plugins, themes, appearance, Agent settings, projects, sessions, MCP/extensions, API proxy and updates. Changes use live desktop controllers and refresh the UI. Existing credentials are redacted in queries.
- Bundle an on-demand documentation directory with separate guides, examples and an operation reference. `/help` returns its location. Explicitly distinguish Umeko provider/theme configuration from upstream Pi configuration.
- Support batch requests and bounded deferred jobs for changes that need idle tasks. Keep calls associated with their originating chat when the visible conversation changes. Report queued and accepted work separately from applied changes.
- Load long conversations through a disposable background index, viewport pages and bounded LRU caches. Preserve drafts, reading positions, native history and Agent context. Copy selections across unloaded pages without blocking the interface.
- Fix variable-height chat scrolling/history jumps, blank Windows web previews, sidebar dragging and release-to-collapse behavior. Prefix fork titles with `(Fork1)`, `(Fork2)`, etc.
- Keep ordinary hover hints transparent to pointer input, so a hint covering a neighboring button cannot consume its first click. Interactive question-mark help retains selection and delayed dismissal.
- Trust system-installed certificates alongside bundled roots for updates. After a system-proxy connection failure, try verified direct access and report the actual route. Certificate, hostname and archive SHA-256 verification stay enabled.

Validation covers the actual Agent-to-desktop tool round trip, live configuration and theme changes, deferred/background-chat ownership, native sessions, long-chat paging/copying and loopback TLS/proxy handshakes. Synthetic long-chat checks are local measurements, not production benchmarks.
