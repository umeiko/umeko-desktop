# Umeko Desktop v0.4.3

- Follow system proxy settings for version checks and update downloads, including HTTP/HTTPS and SOCKS5 proxies. On Linux, also read GNOME/Cinnamon manual proxy settings when Qt does not provide them.
- Keep downloaded parts across interruptions, pauses and app restarts. Automatically reconnect with bounded retries and resume from saved byte offsets instead of restarting the entire download.
- Use up to three concurrent connections for larger updates; fall back to a single connection when the server does not support byte ranges.
- Show transferred bytes, speed, estimated time remaining and the active proxy route. Add Pause/Resume controls and keep download progress below 100% until SHA-256 verification succeeds.
- Distinguish network, server, disk and checksum failures. Only verified, complete archives can be installed; unrelated files in Downloads are preserved, and proxy credentials are not saved in download jobs or logs.

Validation includes interrupted connections, pause/restart, range fallback, invalid responses, checksum failures, native/Python UI checks, and a complete official GitHub download through a system proxy.
