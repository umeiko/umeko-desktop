# Umeko 0.7.3

- **定时唤醒任务**：新增单次定时与周期触发，可向本会话主 Agent 或已通过 AgentBus 关联的全局 Agent 发送预写消息。周期支持小数天、小时、分钟，最短 15 秒，每会话最多 5 个定时器。
- **Agent 自主管理计时器**：沿用现有 Widget API 创建、列举、启用、停用、删除及查看记录；支持立即开始的单次倒计时。已到期并完成投递的模型单次计时自动复用原槽，保留 ID、颜色和历史，不覆盖进行中、手动编辑或周期任务。
- **统一定时任务界面**：使用 Umeko 现有控件与主题，采用简约钟表图标，集中展示目标、时间、启停状态与投递记录，移除独立运行配置区。
- **Widget 按需注入提示词**：启用的 Widget 可声明简短静态指引，在下一次请求生效；定时任务指引直接提供专属文档入口和完整的 5 分钟唤醒示例。可在系统提示词 Widget 中查看来源。
- **暂缓内置任务记录 Widget**：本轮不随应用构建或 SDK 示例分发，已有记录与源码保留。
- **改进聊天与文件操作**：侧栏并列提供新会话与搜索入口，聊天选中文本可附加为项目 Markdown 文件；删除会话时清理受管数据，导入时验证原生会话文件。

本次优先提供 Windows x64。其他平台仅在同版本构建通过验证后提供，未构建的平台不显示下载按钮。

**0.7.1 作为里程碑版本继续保留**，其标签、Release 和下载资产不随本次发布清理。
