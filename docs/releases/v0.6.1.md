# Umeko Desktop v0.6.1

## 中文

- 新增共享终端 Widget：用户和 Agent 在同一个可见终端中读取输出、输入命令和中断任务。支持多终端、上下分栏、拖动调整比例及取消分栏；取消分栏保留进程和输出。右键附加到聊天后，Agent 才能访问对应终端。
- 提供文件管理器、版本管理和应用级 Widget 服务。插件入口位于聊天右下角，设置集中在「Agent → 插件管理」；SDK 和使用文档可从软件中导出。
- 接入桌面宠物 Widget，低频跟随任务状态，支持互动和导入自定义外观。与终端同时运行，切换聊天、关闭预览面板时保持应用级生命周期。
- Widget 通过统一的 `umeko_desktop` 接口与 Agent 双向通信，支持主动通知、异步结果和按需读取完整文档。插件必须提供简短介绍、使用文档和公开方法声明。
- 提供 21 个内置 Widget 图标及包内自定义图标，支持预览和复制清单配置；修复空图片地址导致内置图标消失的问题。
- 工具调用中的文件名支持点击预览，右键菜单与聊天文件卡片统一：附加到聊天、复制文件、复制路径及在文件管理器中打开。
- 支持选择和导入角色资源包，保留角色动画、彩蛋及主题适配。改进 Widget 设置折叠和 Windows 测试中的路径、清理及异步控件等待。

## English

- Add a shared terminal Widget: users and Agents read output, type commands and interrupt tasks in the same visible shell. Support multiple terminals, adjustable vertical splits and unsplitting without ending either process. Agent access requires attaching the terminal to that chat.
- Include File Manager, Version Control and application-lifetime Widget services. Open Widgets from the chat launcher and manage them under **Agent → Plugin management**. Export the SDK and usage documentation from the app.
- Integrate the desktop pet Widget with low-frequency task activity, interactions and custom appearances. The pet and terminal coexist across chat switches and closed side panes.
- Reuse `umeko_desktop` for bidirectional Widget communication, attributed notifications, asynchronous results and on-demand documentation. Packages provide a short introduction, full usage guide and declared public methods.
- Offer 21 built-in Widget icons, bundled custom artwork, previews and copyable manifest entries. Fix built-in icons disappearing when the custom image URL is empty.
- Preview files directly from tool history. Reuse chat file-card context menus to attach, copy files, copy paths and reveal files in the system file manager.
- Select and import character packs while retaining animations, interactions and theme support. Improve collapsed Widget settings and Windows test handling for paths, cleanup and asynchronous controls.
