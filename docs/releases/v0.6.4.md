# Umeko 0.6.4

- 输入 `/` 即可打开紧凑分组菜单，选择 `/compact`、`/reload`、当前已启用的 Widget 或可用 Skill。支持可见名称、中文拼音和首字母匹配；`/s` 到 `/skills` 都能展开技能。选择技能会附加整个文件夹，保留人工发送步骤。
- Skill 管理 Widget 默认启用；全局及当前会话的停用开关会关闭对应范围的技能发现和加载，子智能体继承该设置。当前回复完成后应用变更，文件和原有配置保留。收起面板只隐藏界面。
- Skill 管理标题旁增加圈问号，解释名称、简介和路径进入发现索引，以及技能正文和资料按需读取的机制。
- 首次运行预装 PDF、Skill Creator、GitHub Fix CI、Humanizer、Grounded Citations、Systematic Debugging、Microsoft Office、Dogfood 和 Archify。Office 同时包含从 DeepSeek Harness 适配的交付、渲染与重算工作流。
- 保留每个技能的许可、来源提交与文件校验清单，适配 Pi Agent 的工具和产物展示。用户已编辑、删除或同名自建的技能不会被启动过程覆盖或重新安装。Office/PDF 的 Python 依赖、LibreOffice、GitHub CLI 和浏览器自动化仍按任务需要配置。

本次为 Python 桌面版更新。
